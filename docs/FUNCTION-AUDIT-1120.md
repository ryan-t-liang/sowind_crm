## 工单状态精确对照

1. 申请成功，待专属顾问与您联系
2. 已拒绝
3. 门店跟进中
4. 专属配件已寄送
5. 作品已发回
6. 作品已收到，待售后
7. 作品已完成售后，待付款
8. 作品已寄回，待签收
9. 服务完成

## 售后原因精确对照

更换电池、全面保养服务、部件遗失/损坏、功能失效、腕表抛光/翻新、走时快、走时慢、走停、腕表防水、万年历调整、摔落/震撞、消磁、其他问题。

## 明确边界

- 三个包均为前端静态原型，不包含真实账号、微信授权、数据库、文件上传、短信、邮件、支付或物流 API。
- 后台的更改持久化在浏览器 `localStorage`；维修图片仅保存本地文件名，不上传文件内容。
- 邮箱及服务条款正文属于品牌方内容，代码已经提供展示位置和交互，但上线前仍需品牌正式确认。
